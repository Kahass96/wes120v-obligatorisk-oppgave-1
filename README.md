# Minimalt Vite-prosjekt (WES120V)

Et enkelt Vite-prosjekt opprettet med Vanilla-templaten og ryddet for alt demo-innhold. Prosjektet består kun av en forenklet `index.html` som fungerer som entrypoint.

## Installasjon og oppstart
For å kjøre prosjektet må Node.js og pnpm være installert.

Installer avhengigheter:
```bash
pnpm install

Start utviklingsserveren: pnpm dev
Gå ut/slutt serveren: q + Enter
